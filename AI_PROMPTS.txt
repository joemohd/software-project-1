------------------------------------------------

PROMPT: How does this backend manage file uploads?

------------------------------------------------

RESPONSE: The backend uses NestJS’s Multer integration for a single image-upload endpoint:

- **Endpoint:** `POST /api/upload/image`, with a `multipart/form-data` field named `file` (`upload.controller.ts`).
- **Validation:** Only JPEG and PNG MIME types are accepted, and each file is limited to 5 MB (`image-upload.options.ts`).
- **Storage:** Files are written to `./uploads` with a random UUID filename and the original extension. The directory is ignored by Git (`image-upload.options.ts`, `.gitignore`).
- **Serving and response:** The app exposes that directory under `/uploads`; after a successful upload, the endpoint returns `{ "url": "…" }`, built from `BASE_URL` (default `http://localhost:3000`) (`main.ts`, `upload.controller.ts`).

The upload module is registered in the app. The current endpoint is generic: it doesn’t associate files with a specific post, activity, hotel, or airline, and the documented per-entity image-count limits aren’t enforced here.
